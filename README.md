# PathOS — Goals to Today

**PathOS** is an all-in-one personal productivity system that connects 1–5 year strategic goals (**Future Roadmap**) with daily execution (**Today**) and custom habits & metrics (**Tracker Maker**).

## Tech Stack
- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS + Lucide React icons
- **Persistence:** LocalStorage (`pathos:v1`) with JSON export/import & demo state reset

## Getting Started

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173/` in your browser.
